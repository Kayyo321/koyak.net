03  /  Kernel notes

First boot.

OsDev starts with a 512-byte boot sector. The assembly switches the processor into 32-bit protected mode, then hands control to a small C kernel.

There’s no window system here. To put a character on screen, the kernel writes directly into VGA text memory.

Where does the text go?

In color text mode, VGA memory starts at 0xB8000. Each character cell takes two bytes: one for the character and one for its color attributes.
